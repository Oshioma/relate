# Research batch 04 (Oshi, 2026-11-02)

Supplied: `seven_day_guidance_2026_11_02.json`, a seven-day preview for 2 to
8 November 2026 (East Africa Time), kept here as
`batch-04.seven_day_guidance.original.json`. The batch's other files repeat
batches 01 to 03 unchanged.

`batch-04.v1.json` turns the seven days into **daily notes**, a record type
added for this batch (`calendar_daily_notes`):

- Each note is one modern, optional suggestion for one date ("Review
  unfinished work"). The batch is explicit that these are modern editorial
  suggestions, not historically attested instructions, and must not be
  attributed to any people. So a note belongs to no culture, is tagged
  *modern interpretation* (the import refuses one that isn't), and the
  calendar shows it as "A suggestion for the day · modern and optional", with
  the batch's disclaimer.
- Each note cites timeanddate.com's Dar es Salaam Moon phases for the phase it
  was written around, with a locator saying the suggestion itself is modern.
- The Moon phase is not stored: the calendar calculates it.
- `unmapped_traditions` and the Akwasidae on 22 November need nothing new:
  no Māori, Hawaiian, Igbo or Yoruba night is placed on a date, and Akwasidae
  is already there from batches 01 and 03.

Everything is a draft until a reviewer publishes it ("Daily suggestions
(modern)" in the review list).
