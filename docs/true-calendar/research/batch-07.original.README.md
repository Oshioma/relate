## Import rules

- Do not publish unreviewed drafts or assign Gregorian dates to lunar day numbers.
- Greek material comes from a single author and is **not** a universal ancient Greek calendar.
- Egyptian source is a museum description of a civil-calendar omen papyrus, **not** a lunar phase cycle.
- Hawaiian month records describe Hawaiʻi seasonal conditions; do not project them onto Zanzibar.
