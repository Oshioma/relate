# Research batch 06

Oshi's batch 06 (76 records, `batch-06.original.json`, README in
`batch-06.original.README.md`), converted to `batch-06.v1.json` by
comparing every record with batches 01–05.

## Duplicates merged (34): not imported again

- **30 Hawaiian nights.** Same source (Kapiʻolani Community College, Oʻahu
  days) and the same claims, night for night, as batch 01's
  `oceania.hawaiian.oahu-lunar-nights.night-01` to `night-30`. Batch 01's
  records (and batch 05's practices and conflict groups on them) stand.
- **4 Igbo market days.** The same Eke, Orie, Afọ, Nkwọ positions as batch 02's
  `africa.west.igbo.market-week.cycle.*`, and the 2022 Nkwerre paper is already
  cited on that cycle by batch 05. No new claim.

## New (42 records + 12 practices)

- **Source** `src.teara-maramataka`: Te Ara, "Maramataka – the lunar calendar".
- **30 nights**, system `oceania.maori.kahungunu-maramataka` (Ngāti
  Kahungunu as recorded by Te Ara). Night names, positions and meanings as in
  the batch. Favourability read from the wording. 12 nights whose meaning names
  an activity (eeling, crayfish, fishing, gathering sea food, "good day for
  work", Whiro's caution about food-seeking) also get a practice record.
  This is a different source and iwi from batch 01's maramataka (Te Papa), so
  nights with the same name are kept as separate claims; the feed shows them
  on one card with both sources.
- **12 months**, system `oceania.maori.tuhoe-months` (Ngāi Tūhoe,
  Tūtakangahau's account, as recorded by Te Ara), in `months`. Seasonal, never
  dated, with the caution that they describe Aotearoa's seasons, not Zanzibar's.

## Notes

- The batch's generic `modern_application` text ("Consider this tradition…")
  is the same on all 76 records, so it is not stored as a modern reading.
- The batch reuses research IDs (`b06-māori-01` is both Whiro and Pipiri). The
  stable keys above are used instead, and the research ID is kept as the
  citation locator (`b06-tuhoe-month-NN` for the months).
- Everything imports as draft. Nothing is published until a reviewer
  publishes it.
- Dates: the batch says none of these have verified dates. On 2 November 2026
  Oshi chose to show lunar nights with an approximate date counted from the
  calculated new Moon, labelled "Approx." and "Lunar guidance", with the
  counting rule shown on the card. The months and market days stay undated.
